This website uses `wgpu` to render the Mandelbrot set quickly on the browser!

To build it yourself, run `cargo install wasm-pack` and try `wasm-pack build --target web`.

Even though there are many issues with this, you can zoom in to your heart's content, and the UI isn't too cluttered. I consider this okay for now :)
